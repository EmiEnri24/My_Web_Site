My Projects



Taco's shop webpage

Project Type: Responsive Web Design
Tech Stack: HTML, CSS
This was my first fully responsive webpage, designed to simulate a taco shop's online presence. Working in this project, I gained hands-on experience with HTML structure: 2 of the most challenging components were building a table and creating a functional contact form.
About CSS, it focused not only on aesthetics, but also in scalability and maintainability. Using a :root section to centralize design values (colors, fonts, spacing, etc), increasing organization and efficiency making updates in the future.



Weather Page with API (Tutorial Reference)

Tech Stack: HTML, CSS, JavaScript, OpenWeather API
This was my first interactive webpage integrating a third-party API to deliver real-time weather updates based on user input.
Key Features:

  • API Integration: dynamic city-based weather retrieval using OpenWeatherAPI
  • Input validation to handle blank or whitespace-only entries
  • 404 error handling with a custom "Page Not Found" view for invalid routes



Notes CRUD App (Django Backend and React Frontend - Tutorial Reference)

Tech Stack: Django (Backend), React (Frontend), REST API, JSON Web Tokens
This was my first full-stack project combining Django and React, I built a responsive Notes CRUD (Create, Read, Update, Delete) platform.
It marked a major milestone in my understanding of backend–frontend integration.
Backend Django

  • Built a RESTful API using serializers, views, and URL routing.
  • Implemented both local and cloud-based databases for storage.
  • Structured models and endpoints to support secure data operations.

Frontend React:
  • Implemented token-based authentication to control user access.
  • Designed dynamic routes for seamless navigation across pages.
  • Designed responsive Contact-me platform with automatic emails to my email using smtpJS and elasticEmail.
